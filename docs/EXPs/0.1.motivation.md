    Retrieval round total: 1.7324s
        Router prefill before doc_query: 0.0768s, 把问题编码到 router 层
        doc_query retrieval core: 1.2339s, 拿 query states 去和 memory bank 中所有文档块的 router key 做匹配；在单卡或多卡上打分；选top-k文档ID
        Retrieval round tail (ID generation/context copy): 0.4355s, 从生成字符串里解析出文档编号，把编号映射回真实文档，拼接成 source context，tokenize，送回模型作为下一轮输入
    Answer prefill to first token: 0.5060s, 读完 retrieved context，把这些 token 编码进 KV cache， forward 到首 token
