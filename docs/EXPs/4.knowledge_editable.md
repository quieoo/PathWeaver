# evaluation setting

Post-update Correctness / Stale Answer Rate
    当知识单元或 DAG edge 被更新后，模型是否真的使用新知识，而不是继续输出旧答案。
        - 更新轮次：0,1,2,3,4,5
        - 更新类型：
            插入新属性 – 新问题，新答案
            修改属性 – 问题不变，答案变
            修改关系 – 问题变，答案不变
            插入新关系 （+新属性） - 新问题，新答案

## round-datasets

从已有 tripled 数据集中抽出 round0 的 100 个样本
每轮随机选 20 个样本
随机执行 attribute_update / attribute_insert / relation_update / relation_insert
通过 OpenAI-compatible 接口调用你后端的 qwen3.5-27B 生成新的 question / answer / triple_list
